## 维护规则

- 大屏只维护 `groundstation.html`，旧演示版不再入库。
- KT 板只维护 `kt-board/index.html` 及其引用图片；PDF 属于可再生成产物，由 `.gitignore` 排除。
- `*preview*.png`、培训 PDF、浏览器截图和临时渲染结果不入库。
- 不使用虚构的实测数据冒充实验结果；演示数据必须明确标记为“演示”。
