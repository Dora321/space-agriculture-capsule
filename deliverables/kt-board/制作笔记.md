# KT 展板 · 程序化排版制作笔记（可复用）

> 这次做《太空农业智能育种舱》KT 板的方法、命令和踩坑。下次做海报/展板/信息图直接照这套来。

## 一句话方法

**纯 HTML/CSS 写版面 → 无头 Chrome 渲染成印刷级矢量 PDF。**
声明式 + 物理单位(mm) + 浏览器引擎 = 排版精准、可矢量印刷、改一个变量全局生效。本质就是 HyperFrames / Remotion 那套"代码→确定性渲染"的思路，静态海报用纯 HTML 最轻。

- **适用**：信息密集、要精确尺寸、要矢量印刷、要反复迭代的展板/海报/信息图。
- **不适用**：需要复杂照片合成或手绘风（那用 PS/AI）。照片本身仍是位图，只有版式/图标/文字是矢量。

---

## 一、工程骨架（HTML/CSS）

- **画布**：`.board { width:1200mm; height:600mm }`，**所有尺寸都用 `mm`**（字号、间距、圆角、色条），所见即印刷尺寸。
- **打印**：`@page { size:1200mm 600mm; margin:0 }`；元素加 `print-color-adjust:exact`（否则背景色/底纹不印出来）。
- **屏幕预览缩放**：`@media screen { .board{ zoom:.3 } }` / `@media print { .board{ zoom:1 } }`。
- **布局**：CSS Grid 切行列（`grid-template-rows/columns` 用 mm），面板内用 Flexbox。
- **设计系统**：用 CSS 变量定义配色/字号/圆角；**复用同一个卡片组件**（这次叫 `.feat`），风格自动统一。
- **图标**：内联 SVG `<symbol>` + `<use href="#ic-xx">`，统一**线性风格**（`fill:none; stroke:currentColor`）。别一处用线图标、一处用填充圆盘——会显得不协调。
- **二维码**：CDN 引 `qrcode-generator`，用模块矩阵现生成 SVG（矢量、印刷清晰）。**需联网**。
- **字体**：思源黑体 / 微软雅黑；正文别用宋体（远观细笔画糊）。最多两种字体。
- **配色**：冷色科技底 + 一处暖色强调（成本/安全/2035 用橙）。深色标题带压在浅底上做视觉锚点。

## 二、渲染命令（Windows / headless Chrome）

Chrome 路径：`C:\Program Files\Google\Chrome\Application\chrome.exe`

**预览截图（PNG，走 screen 媒体，含 zoom）：**
```powershell
& $chrome --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=2 `
  --user-data-dir="$env:TEMP\cr_xxx" --window-size=1700,1080 --virtual-time-budget=6000 `
  --screenshot="preview.png" "file:///<ASCII路径>/index.html"
```

**印刷 PDF（矢量，走 print 媒体，@page 尺寸生效）：**
```powershell
& $chrome --headless=new --disable-gpu --no-pdf-header-footer `
  --user-data-dir="$env:TEMP\cr_xxx" --virtual-time-budget=6000 `
  --print-to-pdf="board.pdf" "file:///<ASCII路径>/index.html"
```
- `--virtual-time-budget=6000` 给二维码/JS 渲染留时间。
- `--user-data-dir` 用独立临时目录，避免和已开着的 Chrome 抢锁。
- 浏览器里手动导出：`Ctrl+P → 另存为 PDF → 边距"无" → 勾"背景图形"`。

## 三、迭代工作流（关键，别靠肉眼估）

**渲染 PNG → 读图 → 切块放大核对间距 → 改 → 再渲染。** 缩略图太小看不清间距，用 System.Drawing 把大图切成 4 块逐块看：

```powershell
Add-Type -AssemblyName System.Drawing
$img=[System.Drawing.Image]::FromFile("full.png")
function Crop($src,$x,$y,$w,$h,$out){
  $bmp=New-Object System.Drawing.Bitmap $w,$h
  $g=[System.Drawing.Graphics]::FromImage($bmp)
  $g.DrawImage($src,(New-Object System.Drawing.Rectangle 0,0,$w,$h),
               (New-Object System.Drawing.Rectangle $x,$y,$w,$h),[System.Drawing.GraphicsUnit]::Pixel)
  $bmp.Save($out,[System.Drawing.Imaging.ImageFormat]::Png);$g.Dispose();$bmp.Dispose()
}
Crop $img 50 150 1460 740 "q_TL.png"   # 左上，其余象限同理
$img.Dispose()
```

## 四、踩过的坑（最省时间的一节）

| 坑 | 现象 | 解法 |
|---|---|---|
| **百分比高度 + flex + zoom 算炸** | 柱状图 `height:%` 在 `zoom` 下撑满半屏、盖住别的栏 | 柱子/容器用**固定 mm 高度**，别用 `%` 高度 |
| **中文路径渲染失败** | `file:///...太空.../index.html` 出不来图 | 用 ASCII 路径；或复制到无中文临时目录渲染；或 percent-encode UTF-8 |
| **移动时 PDF 被锁** | `Move-Item` 报 "being used by another process"（Chrome/预览开着） | 用 `Copy-Item`（读锁允许复制）；或先关预览 |
| **沙箱护栏误触发** | 同段 PowerShell 里 `Remove-Item` + `C:\Program Files` chrome 路径被拦 | **渲染和清理分开写**，删除命令里别出现 chrome 路径 |
| **PDF 太大（>10MB）** | 嵌入 PNG 原图，board.pdf ~20MB | 图片降采样 + 转 JPEG（见下），换 src 引用后重渲染 → ~2MB |
| **二维码空白** | 用 CDN 库现生成 | 打开/打印时**需联网**；离线可换内嵌矩阵 |

**图片压缩（<10MB 分享版）：**
```powershell
# System.Drawing 缩放到目标宽度 + JPEG 质量 80 保存；团队头像缩到 ~520px，插画 ~1600px
$ep=New-Object System.Drawing.Imaging.EncoderParameters 1
$ep.Param[0]=New-Object System.Drawing.Imaging.EncoderParameter([System.Drawing.Imaging.Encoder]::Quality,[int64]80)
$bmp.Save($out,$jpgCodec,$ep)
# 再把 index.html 里 *.png 引用替换成 *_c.jpg，另存 board-lite.html，重新 --print-to-pdf
```

## 五、这次成稿的版面结构（可当模板）

横版 1200×600mm，5 行栅格：

1. **标题带**（满宽深色渐变）：主标题 + 副标题 + 学校/战队 + 遥控大屏二维码
2. **三栏主体**：① 育种演进（插画 + 横向时间轴 + 周期数字）｜② 系统架构（图 + 细节行 + 技术标签）｜③ 实物 + 大屏截图（并排大图）
3. **主数字带**：4 个大数字（2 米外可见）+ 小字说明，最易被追问的那个（成本）用橙色高亮
4. **底部四栏**：工作闭环（含实例 + 安全护栏）｜下一步优化｜核心创新三支柱｜团队（横排大头像 + 现在/2035 双职责）
5. **页脚条**：项目名 + 金句 + 网址

## 六、内容红线（比赛展板，别翻车）

- **实物 / 演示 / 数据 = 真图真数**，绝不用 AI 生成（评委一眼识破，毁掉"真系统"可信度）。
- 概念 / 未来 / 历史镜头才用 **AI 或库存素材**（深空、地球、未来场景）。
- 不确定的就标 **"示意"**，别假装跑完（如多代育种曲线）。
- **数字要和项目仓库的权威值一致**：测试数 / 成本 / 硬件件号是"跨文档不变量"，改一处必须同步所有镜像（见 `CLAUDE.md` / `ARCHITECTURE.md` §11 的不变量表）。做完展板记得回灌仓库或核对。
- 名人肖像（如袁隆平）不要 AI 生成。
