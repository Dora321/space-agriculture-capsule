## #47 KT 板重做：HyperFrames / 纯 HTML 程序化排版

旧的 `deliverables/KT板打印稿-120x60.html` 是手写版式；这次换成**程序化排版**思路（HeyGen HyperFrames 那一套：纯 HTML/CSS → 无头 Chrome 渲染成印刷级 PDF），新板放在 `deliverables/kt-board/`。

- **技术**：整张板用 `mm` 物理单位（1200mm×600mm，所见即印刷尺寸），CSS Grid + Flexbox 精确分区，`@page { size:1200mm 600mm }` 让 Chrome 打印成精确尺寸的矢量 PDF；图标用内联 SVG `<symbol>`/`<use>`，二维码用 `qrcode-generator` 现生成 SVG。改一版就 `--screenshot` 渲染 PNG、切块放大核对间距（渲染—检查闭环）。
- **产物**（`deliverables/kt-board/`）：`index.html`（源）+ `board.pdf`（≈19MB 完整矢量印刷版）+ `cabin/dashboard/evolution/chen/yang/huhan.png`（实物图、大屏截图、育种演进插画、三人 2035 形象照）。另有用户压缩的 `（已压缩）board.pdf` ≈2.2MB，作 <10MB 分享/上传版。
- **版面**：浅色高清主题。① 育种演进（插画 + 横向时间轴 + 育种周期 数千年→8–10年→数月）｜② 双层架构（图 + 降级链/自治边界/大屏只读 + 技术标签）｜③ 实物 + 遥控大屏（并排大图）｜主数字带 159/8天/8种/¥135｜④ 工作闭环（含实例 + 安全护栏：动作时长上限·每小时限频·每次动作间隔）｜下一步优化（摄像头 / 多模态 AI / AI 育种评分系统）｜太空环境三大设计（在轨育种验证·断联自治·AI+本地规则双层决策）｜育种团队（陈美伊/杨灏辰/张煦涵，现在/2035 双职责）。二维码指向遥控大屏 `43.156.68.157:8790`。
