## 六、比赛前 1 小时 · 快速检查

**硬件上电**
```
□ ESP32 通电 → OLED 第 1 页湿度大字正常
□ 红/黄键翻页 → 三页都正常
□ 蓝键 → 菜单进入/退出正常
□ WS2812 → 11 颗自检全亮
□ 土壤/DHT11 读数合理
□ 继电器/水泵 → 通电动作正常、储水箱注水回水通畅
□ 树莓派开机 → 网关连上 ESP32（OLED 第三页 PI:OK）
□ 摄像头 → 手动采集一张成功，大屏视觉面板出图
```
**联机 / 演示**
```
□ 树莓派联网 → DeepSeek 测试响应正常
□ 大屏（在树莓派上）→ 数据刷新、视觉面板有真实数据
□ 断网演示彩排 → 拔 UART 线，OLED 显示 PI:OFF、浇水不停；插回 PI:OK
□ 浇水 + 储水循环彩排 → 捏传感器触发浇水、多余水回流
□ 故障预案 L1/L2/L3 切换话术过一遍
```
**人员**
```
□ 队员1：开场+收尾倒背如流、能控场、诚信题答得稳
□ 队员2：断网自治演示流畅、两层决策讲清、大屏操作熟练
□ 队员3：浇水+储水循环演示流畅、能讲安全护栏
```
